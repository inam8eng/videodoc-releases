## What is VideoDoc?

VideoDoc turns a YouTube link or a local video into **one PDF your AI can actually see**: the full timestamped transcript plus the video's own key images, in order. Drop the PDF into ChatGPT or Claude and ask anything about a 3-hour video. Everything runs on your computer — nothing is uploaded.

## What is this repo?

This is the **public update feed** for VideoDoc. Installed apps check this repo on launch to detect updates. The app is sold on Gumroad and the source code is private — neither is hosted here.

## Automatic updates

1. VideoDoc checks this repo silently when it starts.
2. When a new version exists, the app shows an **"Update vX.Y.Z available"** pill that opens that version's release page here.
3. Download the new version from your Gumroad library. Windows: run the new `VideoDoc-Setup` over the old one. Mac: click **Shut down** in the old VideoDoc, move its old folder from Downloads to the Bin, then unzip the new one. Your Pro license stays activated.
